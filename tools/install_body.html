CLAUDE CODE SKILL · __VERSION__

사주 스킬

  • Claude Code용
  • 설치 1분
  • Python 3 필요

생년월일시를 말하면 Claude가 사주를 계산하고, 폰에서 보기 편한 손그림 풀이 페이지를 만들어 줍니다.

명령 한 줄로 설치

설치 · 맥 / 리눅스터미널에 붙여넣기 한 번

  1. 터미널을 엽니다. 맥은 Spotlight(⌘+스페이스)에서 "터미널"을 찾으면 됩니다.

  2. 아래 노란 버튼을 눌러 명령을 복사합니다. 명령이 길어서 화면에는 줄여서 보여 줍니다.

  3. 터미널에 붙여넣고 엔터. "설치 완료"가 나오면 끝입니다.

  4. Claude Code를 새로 엽니다. 열려 있었다면 껐다 켭니다.

mkdir -p ~/.claude/skills && echo '…스킬 파일 __KB__KB…' | base64 --decode | tar -xz -C ~/.claude/skills
전체 명령 보기

설치 · 윈도우PowerShell에 붙여넣기

  1. PowerShell을 엽니다. 시작 메뉴에서 "PowerShell"을 찾으면 됩니다.

  2. 아래 버튼으로 복사해 붙여넣고 엔터.

  3. Claude Code를 새로 엽니다.

$b='…스킬 파일…'; [IO.File]::WriteAllBytes("$env:TEMP\saju.tgz",[Convert]::FromBase64String($b)); tar -xzf "$env:TEMP\saju.tgz" -C "$HOME\.claude\skills"
전체 명령 보기

윈도우용 명령은 실제 윈도우에서 돌려 보지 못했습니다. 안 되면 WSL이나 Git Bash에서 위의 맥 / 리눅스 명령을 쓰세요.

쓰는 법그냥 말하면 됩니다

이렇게 말해 보세요

2000년 1월 1일 낮 12시 양력 여자 사주 봐줘

음력 1999년 11월 25일 아침 8시 10분 남자, 사주 풀이 페이지 만들어줘

스킬이 안 잡히면 /saju 라고 먼저 치고 말하면 됩니다.

Claude가 먼저 묻는 것

  • 성별

    대운이 흐르는 방향이 달라져서 꼭 필요합니다.

  • 오전 / 오후

    "11시"만 쓰면 낮인지 밤인지 묻습니다.

  • 양력 / 음력

    말이 없으면 양력으로 봅니다. 음력도 알아서 바꿉니다.

  • 태어난 지역

    시각이 시(時)의 경계에 걸릴 때만 묻습니다.

  • 시간 모름

    세 기둥(년 · 월 · 일)으로 풉니다.

나오는 것

  • 계산

    네 기둥, 음력 변환, 절기, 대운, 세운, 십성, 지장간, 12운성, 공망, 신살, 합충. 스크립트가 계산해서 간지를 틀리지 않습니다.

  • 풀이 페이지

    원국, 오행, 성격, 구조와 신살, 공부·진로, 재물, 가족, 건강, 대운, 앞으로 몇 해, 개운법.

  • 두 겹 풀이

    항목마다 전문 용어 풀이가 먼저, 바로 밑에 쉬운 말 풀이. 버튼으로 쉬운 풀이만 볼 수도 있습니다.

명령이 하는 일붙여넣기 전에 확인

명령 안의 긴 글자는 스킬 파일 __COUNT__개를 압축해 글자로 바꾼 것입니다. 명령은 이것을 풀어서 ~/.claude/skills/saju 폴더에 넣습니다. 그 폴더 밖은 건드리지 않고, 인터넷에서 아무것도 내려받지 않습니다.

__FILES__

지우려면 rm -rf ~/.claude/skills/saju 한 줄이면 됩니다.

절기 시각은 약 ±15분 오차가 있습니다. 절기 바로 앞뒤나 시(時)의 경계에 태어났다면 스킬이 경고를 띄웁니다. 사주는 과학이 아니라 오래된 해석의 틀입니다. 재미와 참고로 보세요.
